# JetBridge — лендинг

Вёрстка лендинга JetBridge (доставка из ОАЭ в Казахстан) по макету из Figma.
Стек: HTML, CSS, jQuery. Только десктоп (1440px), адаптива нет.

## Запуск

Сборки нет — откройте `index.html` через локальный сервер (например, расширение Live Server в VSCode).
Открытие файла двойным кликом может не подгрузить стили из-за `@import` в CSS.

## Структура

```
index.html
css/
  main.css        точка входа (только @import)
  base/           переменные, шрифты, сброс, сетка
  components/     кнопки, заголовок секции, выпадающее меню
  sections/       стили секций (BEM)
js/
  main.js         инициализация модулей
  modules/        menu, scroll, slider, form (jQuery)
img/              изображения и иконки из макета
fonts/            Involve (SIL OFL, лицензия в fonts/OFL.txt)
```
